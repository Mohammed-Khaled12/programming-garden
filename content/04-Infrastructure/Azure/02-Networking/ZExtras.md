
# Network Watcher
دي **أداة تشخيص شبكات مركزية**، بتتفعل تلقائيًا أول ما تعمل أي مورد شبكي.

#### الأدوات الفعلية جواها:

**1. IP Flow Verify**  
بتسألها: "الترافيك من IP كذا لـ IP كذا على بورت كذا، مسموح ولا لأ؟" وبتقولك **بالظبط أي قاعدة NSG** (Subnet أو NIC) المسؤولة عن القرار — أسرع من ما تدور يدوي.

**2. Connection Troubleshoot**  
بتختبر **اتصال فعلي حقيقي** بين مصدر ووجهة (زي VM لـ VM، أو VM لموقع خارجي)، وبتوريك **كل الـ hops** اللي المرور عداها، وفين بالظبط اتوقف لو فشل.

**3. NSG Diagnostics** (فاكرها من موضوع NSG؟)  
"ال IP كذا بيحاول يوصل بورت كذا، ليه بيترفض؟" — بيوريك القاعدة المانعة مباشرة.

**4. Packet Capture**  
بيسجل الـ packets الفعلية العابرة على NIC معينة لفترة زمنية، لتحليل عميق جدًا للمشاكل المعقدة.

**5. Topology**  
بيرسملك بصريًا كل الموارد المتصلة في VNet معينة وعلاقتهم ببعض.


# Traffic Manager
#### المشكلة اللي بيحلها (مستوى مختلف تمامًا)

فاكر Load Balancer (L4، بيوزع داخل Region واحدة) وApplication Gateway (L7، بيوزع داخل Region واحدة كمان)؟ **Traffic Manager بيشتغل على مستوى مختلف تمامًا: DNS، مش على مستوى المرور نفسه خالص.**

#### الفكرة الأساسية

عندك تطبيقك **منشور في أكتر من Region** (زي UAE North وEast US، للـ Disaster Recovery أو تقليل الـ latency عالميًا). Traffic Manager بيشتغل **كـ DNS resolver ذكي** — لما مستخدم يسأل عن اسم الدومين، هو اللي بيقرر **يرجعله IP أنهي Region**، بناءً على استراتيجية (Routing Method) تختارها.

#### أنواع الـ Routing Methods (هتتسأل فيها)

|الطريقة|تختار إزاي|
|---|---|
|**Priority**|يروح للـ Region الأساسية دايمًا، لو وقعت يروح للاحتياطية (فاكر Region Pair؟)|
|**Weighted**|توزيع حسب نسبة تحددها (60% لـ Region A، 40% لـ B)|
|**Performance**|يوجه المستخدم لأقرب Region ليه جغرافيًا (أقل latency)|
|**Geographic**|يوجه حسب موقع المستخدم الجغرافي الفعلي (لأسباب قانونية زي GDPR)|

**الفرق الجوهري اللي هيتسأل فيه بالتأكيد**: **Traffic Manager بيوجه على مستوى DNS بس (بيرجع IP مختلف)** — بمجرد ما المستخدم ياخد الـ IP، بيتصل بيه **مباشرة**، من غير ما Traffic Manager يبقى في مسار المرور نفسه. **Load Balancer/Application Gateway** بالعكس، **المرور نفسه بيعدي عليهم فعليًا** كل مرة.

| المعيار        | Load Balancer | Application Gateway | Traffic Manager          |
| -------------- | ------------- | ------------------- | ------------------------ |
| **المستوى**    | L4            | L7                  | DNS                      |
| **النطاق**     | داخل Region   | داخل Region         | عبر Regions متعددة       |
| **يفهم HTTP؟** | لأ            | أيوه                | لا علاقة له بالمرور نفسه |
| **WAF**        | لأ            | أيوه (SKU مخصص)     | لأ                       |
