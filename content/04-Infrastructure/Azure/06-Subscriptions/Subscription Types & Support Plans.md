
### أنواع الاشتراك (إزاي بتدفع)

| النوع                               | ليه                                                               |
| ----------------------------------- | ----------------------------------------------------------------- |
| **Free Trial**                      | تجربة أولى، رصيد محدود لفترة قصيرة                                |
| **Pay-As-You-Go**                   | تدفع حسب استخدامك الفعلي بس، من غير التزام                        |
| **Enterprise Agreement (EA)**       | للشركات الكبيرة، التزام سنوي بحد أدنى إنفاق، خصومات كبيرة         |
| **CSP (Cloud Solution Provider)**   | بتشتري عن طريق شريك مايكروسوفت (Partner)، مش من مايكروسوفت مباشرة |
| **Azure for Students**              | رصيد مجاني محدود للطلاب، بدون كارت ائتمان                         |
| **MSDN/Visual Studio Subscription** | رصيد شهري مجاني للمطورين المسجلين في برنامج Visual Studio         |
: كل نوع عنده **حدود مختلفة للموارد (Quotas)** — مثلاً Free Trial أو Student عنده حد أقصى منخفض جدًا لعدد الـ VMs أو الـ cores، بعكس EA اللي حدوده أعلى بكتير.

### خطط الدعم الفني (Support Plans)

|الخطة|زمن الرد للمشاكل الحرجة|التكلفة|
|---|---|---|
|**Basic**|لا يوجد SLA للرد، دعم بخصوص الفوترة والحساب بس|مجانية تلقائيًا لأي حساب|
|**Developer**|رد خلال 8 ساعات للمشاكل العامة|رسوم شهرية بسيطة، للتطوير والتجربة|
|**Standard**|رد خلال **ساعة واحدة** للمشاكل **الحرجة (Critical impact)**|رسوم شهرية أعلى، للإنتاج|
|**Professional Direct**|رد خلال **15 دقيقة** للمشاكل الحرجة، مدير حساب فني مخصص|الأغلى، للشركات الكبيرة|

**القاعدة العملية للامتحان**: السؤال غالبًا بيوصف سيناريو "نظام إنتاجي critical، عايزين أسرع رد ممكن" → **Professional Direct**. "شركة صغيرة بس عايزة دعم فني أساسي مدفوع" → **Standard**.
ال**Basic دايمًا مجانية ومفيهاش SLA حقيقي للمشاكل التقنية**، بس بيتاح تلقائيًا.
